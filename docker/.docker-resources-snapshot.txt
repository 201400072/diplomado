Para revertir el total de RAM de Docker Desktop a su valor original:
  1. Abrir Docker Desktop
  2. Settings (engranaje) -> Resources
  3. Mover el slider Memory al valor previo (anotar antes de cambiar)
  4. Apply & Restart
